# ArtGoncalense — Documentação SDD

**Estado:** planejamento inicial; nenhuma implementação ou publicação é considerada concluída.

Projeto hobby de comunidade para artistas publicarem ilustrações originais e fanarts, com apoio financeiro voluntário enviado diretamente ao artista. Não utiliza agentes de IA, MCP ou modelos generativos.

## Ordem de leitura
1. [requirements.md](requirements.md): necessidades e limites.
2. [architecture.md](architecture.md): responsabilidades e tecnologia.
3. [specifications.md](specifications.md): contratos e casos verificáveis.
4. [tasks.md](tasks.md): execução incremental e critérios de conclusão.
5. [api-documentation.md](api-documentation.md): referência planejada dos endpoints.
6. [deployment.md](deployment.md): publicação futura e cuidados com planos gratuitos.
7. [decisions.md](decisions.md): escolhas a confirmar antes de implementar.

## Regras para o Codex
- Ler os documentos antes de propor alterações; indicar conflitos ou lacunas.
- Não implementar automaticamente todo o backlog. Trabalhar somente nas tarefas expressamente autorizadas.
- Antes de implementar tarefa com decisão pendente, solicitar confirmação.
- Não contratar serviços, criar recursos pagos, publicar em produção nem coletar dados reais sem autorização.
- Atualizar status e evidências somente após testes efetivos.
- Não colocar credenciais, chaves Pix privadas, tokens ou dados pessoais reais no repositório.
